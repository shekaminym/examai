# EXAM AI

EXAM AI — настольное приложение для Windows на PySide6. Оно принимает вопрос из системного звука, микрофона, текста или выделенной области экрана и показывает потоковый ответ Gemini. Основной язык распознавания речи — украинский.

## Возможности

- Захват системного звука через WASAPI loopback или микрофона; VAD отделяет фразы от пауз.
- Распознавание украинской речи через Gemini Live с переходом на локальный Whisper при недоступности сервиса или задержке. Словарь `speech_glossary.json` помогает исправлять устойчивые ошибки распознавания.
- Выделение области экрана кнопкой **ВИДІЛИТИ НА ЕКРАНІ**. Изображение передаётся Gemini вместе с запросом, включая задачи с печатным текстом, почерком и формулами.
- Ответ по мере генерации, режимы **FAST** и **SMART**, отображение математических формул.
- Импорт конспектов TXT, PDF и DOCX. Поиск по ним работает сразу; семантический поиск можно включить отдельно.
- Переключатель **Ghost Mode** с замком от случайного нажатия. Режим использует механизм исключения окна из захвата Windows; результат зависит от программы и способа демонстрации экрана.

## Запуск

Нужны Windows и Python 3.10 или новее. Зависимости проверялись с Python 3.10.11. В PowerShell:

```powershell
git clone https://github.com/shekaminym/examai.git
cd examai
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Для ответов Gemini и анализа снимков нужен ключ **Gemini API**. Введите его на вкладке **Налаштування** при каждом запуске или задайте переменную среды перед запуском:

```powershell
$env:GEMINI_API_KEY = "ваш_ключ"
.\.venv\Scripts\python.exe main.py
```

Не записывайте настоящий ключ в файлы репозитория. Приложение не сохраняет ключ в `config.json`; введённый в интерфейсе ключ действует до закрытия программы. Для локального Whisper ключ не нужен. Его модель может загружаться при первом использовании.

## Как пользоваться

1. На вкладке **Налаштування** выберите **Системний звук (Loopback)** для звука компьютера или **Мікрофон** для голоса рядом с вами.
2. Нажмите **СЛУХАТИ** либо введите вопрос вручную. При включённой автоматической отправке распознанный вопрос сразу уходит в Gemini.
3. Для вопроса на экране нажмите **ВИДІЛИТИ НА ЕКРАНІ** и выделите нужную область мышью. **Esc** отменяет выбор. Кнопка **Очистити все** очищает вопрос и ответ.
4. Добавляйте материалы на вкладке **Конспекти**, если хотите учитывать их при ответе.

Звук, отправляемый в Gemini Live, выделенное изображение и текст запроса передаются сервису Google. Импортированные конспекты хранятся в локальной базе; найденные фрагменты могут добавляться к запросу Gemini. История ответов сохраняется локально только при включении соответствующей настройки. Ошибка **HTTP 429** означает лимит API и сама по себе не указывает на ошибку распознавания речи.

## Необязательный семантический поиск

Сначала импортируйте конспекты через приложение и закройте его. Затем в папке проекта выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-rag.txt
.\.venv\Scripts\python.exe index_rag.py --download-model
.\.venv\Scripts\python.exe main.py
```

Модель поиска скачивается один раз в локальную папку `models/`. После изменения конспектов повторите `index_rag.py` и перезапустите приложение. Если семантическая модель не установлена или не успела ответить, остаётся обычный поиск по тексту.
