# EXAM AI 2.4

EXAM AI — настольное приложение для Windows на PySide6. Оно принимает вопрос из системного звука, микрофона, текста или выделенной области экрана и показывает потоковый ответ Gemini. Основной язык распознавания речи — украинский.

## Возможности

- Захват системного звука через WASAPI loopback или микрофона; VAD отделяет фразы от пауз.
- Распознавание украинской речи через Gemini Live с переходом на локальный Whisper при недоступности сервиса или задержке. Словарь `speech_glossary.json` помогает исправлять устойчивые ошибки распознавания.
- Выделение области экрана кнопкой **ВИДІЛИТИ НА ЕКРАНІ**. Изображение передаётся Gemini вместе с запросом, включая задачи с печатным текстом, почерком и формулами.
- Ответ по мере генерации, режимы **FAST** и **SMART**, отображение математических формул.
- Импорт конспектов TXT, PDF и DOCX. Поиск по ним работает сразу; семантический поиск можно включить отдельно.
- Переключатель **Ghost Mode** с замком от случайного нажатия. Режим использует механизм исключения окна из захвата Windows; результат зависит от программы и способа демонстрации экрана.

## Запуск

Нужны Windows и Python 3.10 или новее. Зависимости проверялись с Python 3.10.11. Откройте PowerShell в рабочей копии ветки 2.1 и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Для ответов Gemini и анализа снимков нужен ключ **Gemini API**. Введите его на вкладке **Налаштування** при каждом запуске или задайте переменную среды перед запуском:

```powershell
$env:GEMINI_API_KEY = "ваш_ключ"
.\.venv\Scripts\python.exe main.py
```

Не записывайте настоящий ключ в файлы репозитория. Ключ, введённый в интерфейсе, действует до закрытия программы. Ранее сохранённый ключ остаётся в локальной конфигурации. Для локального Whisper ключ не нужен. Его модель может загружаться при первом использовании.

## Как пользоваться

1. На вкладке **Налаштування** выберите **Системний звук (Loopback)** для звука компьютера или **Мікрофон** для голоса рядом с вами.
2. Нажмите **СЛУХАТИ** либо введите вопрос вручную. При включённой автоматической отправке вопрос уходит в Gemini после сборки реплик и короткой паузы. Auto увеличивает ожидание, если фраза выглядит незаконченной.
3. Для вопроса на экране нажмите **ВИДІЛИТИ НА ЕКРАНІ** и выделите нужную область мышью. **Esc** отменяет выбор. Кнопка **Очистити все** очищает вопрос и ответ.
4. Добавляйте материалы на вкладке **Конспекти**, если хотите учитывать их при ответе.

Звук, отправляемый в Gemini Live, выделенное изображение и текст запроса передаются сервису Google. Импортированные конспекты хранятся в локальной базе; найденные фрагменты могут добавляться к запросу Gemini. История ответов сохраняется локально только при включении соответствующей настройки. Ошибка **HTTP 429** означает лимит API и сама по себе не указывает на ошибку распознавания речи.

## Необязательный семантический поиск

Сначала импортируйте конспекты через приложение и закройте его. Затем в папке проекта выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-rag.txt
.\.venv\Scripts\python.exe index_rag.py --download-model
.\.venv\Scripts\python.exe main.py
```

Модель поиска скачивается один раз в локальную папку `models/`. После изменения конспектов повторите `index_rag.py` и перезапустите приложение. Если семантическая модель не установлена или не успела ответить, остаётся обычный поиск по тексту.

## Окно и производительность

- **Закріпити / Відкріпити** переключает закреплённую панель и свободное окно. В настройках можно выбрать монитор и положение у верхней границы. Закреплённое окно открывается компактной полосой. Стрелка раскрывает полный интерфейс вниз и снова сворачивает его. **Ctrl+Shift+F12** возвращает окно на основной монитор.
- **AUTO** рекомендует профиль по ядрам CPU, общей и доступной RAM и доступности CUDA в CTranslate2. При длительной нагрузке понижает профиль до конца сеанса. Ручной профиль имеет приоритет.
- **ECO** подходит для слабых ПК или дефицита памяти. **BALANCED** сохраняет основные эффекты. **PREMIUM** включает более частую визуализацию и полные переходы. Профили не меняют модель Gemini.
- Для окна с собственной маской скруглений используется непрозрачная подложка, если нативная подложка DWM несовместима с его контуром.
- **Зменшити рух** отключает анимации. Midnight Black используется с чистой конфигурацией, а прежняя синяя тема сохраняется при обновлении конфигурации без поля темы.

## Диагностика

В настройках можно открыть **Вікно замірів**. Для сбора серии замеров в PowerShell:

```powershell
$env:PHANTOM_TIMING = "1"
.\.venv\Scripts\python.exe main.py 2> timing.log
.\.venv\Scripts\python.exe performance_report.py timing.log
```

Отчёт показывает число наблюдений, P50 и P95 по метрикам, присутствующим в журнале. Для сопоставимого прогона используйте одинаковые аудио, модели, настройки, документы и сеть. Отдельно замеряйте первый запуск и работу с уже загруженными моделями.


## Живые карточки Compact Dock

Под верхней панелью появляются распознанный вопрос и потоковый ответ. У длинных
ответов есть прокрутка и раскрытие стрелкой. Кнопка × скрывает карточки, а нажатие
на статус верхней панели возвращает их. Стрелки в карточке переключают ответы
текущего сеанса, кнопка «Історія» открывает полную вкладку.

При включённой диагностике метрика `dock_first_paint_ms` измеряет время между
выдачей первого текста рабочим потоком и началом отрисовки карточки Qt.


## Настройки и файлы в 2.4

Шестерёнка в Compact Dock открывает настройки у правой границы выбранного
монитора. Настройки внешнего вида применяются сразу. Изменения модели, аудио
и общих параметров сохраняются по кнопке «Зберегти». Закрытие без сохранения
отменяет изменения в этой форме. Прозрачность ограничена 8%, а при запросе
Ghost Mode окно остаётся непрозрачным.

Чтобы спросить о файле, укажите его имя, например `requirements.txt`. При
совпадении нескольких имён выберите документ в «Конспектах». Записи `-r` и
`-c` отображаются как ссылки на другие файлы. Приложение их не читает с диска
и не запускает установку зависимостей.
