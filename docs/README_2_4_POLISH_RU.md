# EXAM AI 2.4: точечные исправления и макет «Підписки»

## Установка на Windows

1. Закройте EXAM AI. Скопируйте его папку для резервной копии.
2. Распакуйте `EXAM_AI_2_4_FAST_POLISH.zip` **в папку с вашим `main.py`** и подтвердите замену файлов. Личный `config.json`, база данных, конспекты и ключи API в архив не входят.
3. Если зависимости ещё не установлены, выполните `python -m pip install -r requirements.txt`.
4. Запустите `python main.py`.

## Что исправлено и почему

| Проблема | Причина в исходниках 2.4 | Изменение |
| --- | --- | --- |
| Белый пунктир при выборе раздела настроек | `QListWidget` рисовал системный `State_HasFocus` поверх стиля выбранного пункта | Делегат списка снимает только стандартный рисунок фокуса и рисует тонкую синюю рамку; клавиатурный фокус и стрелки работают |
| Сообщение о неподтверждённом Ghost Mode | Скрытое окно настроек проверялось как обязательное до показа, а `WinIdChange` мог приходить в промежутке между старым и новым HWND | Необязательное скрытое окно проверяется при показе; после смены HWND проверка выполняется после завершения перехода Qt. Настоящая ошибка Windows остаётся видимой |
| Заедающий ползунок «Інтенсивність тонування» | Каждый `valueChanged` записывал конфигурацию и пересобирал стили обоих окон и карточек | Во время перетаскивания обновляются процент и маленький образец цвета; полное применение и запись — после отпускания. Для клавиатуры действует короткая задержка сохранения |
| Лишний SMART | Старый файл настроек мог включить длинный промпт, больший бюджет и другой размер RAG | Переключатель удалён из главного окна и Dock, старое значение принудительно читается как FAST. Сохранены прежние быстрый промпт, бюджет и потоковая генерация |
| Анимация при OFF | Режим OFF учитывал собственные переходы не везде и оставлял эффекты всплытия Qt | Единый Motion Manager останавливает декоративные анимации, отключает эффекты меню и списков Qt и учитывает Reduce Motion Windows |
| Заставка и пауза при запуске | Дополнительная фраза и фиксированные 850 мс ожидания | Только «EXAM AI» и индикатор; готовое главное окно открывается на следующем цикле Qt без фиксированной задержки |

При запуске появляется понятное окно ошибки, если инициализация действительно завершилась исключением. Страница **«Підписки»** повторяет палитру и композицию образца: четыре срока, цены 149/399/699/1299 грн, статус «відсутня» и «Найвигідніше» над тарифом 399 грн. Обведённой подписи про отдельный API-ключ нет. **Кнопки «Оформити» пока отключены:** платежей, аккаунтов и ограничений доступа эта версия не добавляет. При узком окне карточки переходят в два столбца.

Проверены быстрый ответ со старым `answer_mode=smart`, сборка голосового вопроса, Gemini streaming с имитацией ответа, поиск RAG, изображения, Live Cards, настройки, Ghost Mode, возврат окна и закрытие. Тесты не отправляют звук или ключи в сеть.

### Замеры до и после

Локальные прогоны на Windows 10 build 19045, Python 3.10, PySide6, с синтетическим UI и без Gemini. Для строки интерфейса — медиана трёх отдельных процессов; для Ghost Mode — медиана трёх прогонов по шесть переключений. Цифры зависят от ПК и не характеризуют сетевой ответ.

Для повторения замеров из корня проекта запустите `python tools/benchmarks/benchmark_ui_probe.py` и на Windows `python tools/benchmarks/benchmark_ghost_probe.py`. Первый пробник использует виртуальный дисплей Qt и не открывает окно на рабочем столе; второй создаёт настоящий HWND, проверяет флаг захвата и затем закрывает окно. Оба работают с временной конфигурацией и имитацией недоступного аудио и не требуют API-ключа.

| Замер | Исходник 2.4 | Эта версия |
| --- | ---: | ---: |
| Создание и первый показ UI, offscreen | 187,36 мс | 181,56 мс |
| Один шаг второго ползунка, offscreen | 98,58 мс | 0,56 мс |
| CPU на 12 шагов ползунка | 1156 мс | 16 мс |
| Открыть и закрыть список Qt, offscreen | 0,24 мс | 0,30 мс |
| Переключить Compact Dock, offscreen | 2,42 мс | 2,49 мс |
| Память процесса после UI-пробы | 85,19 МиБ | 83,42 МиБ |
| Переключить Ghost Mode, реальный HWND | 36,26 мс | 18,10 мс |

Во всех выполненных переключениях Ghost Mode Windows подтвердила `0x11` при включении и `0x00` при выключении. Исходная версия **не воспроизвела** заявленную периодическую ошибку в этой пробе, поэтому изменение устраняет обнаруженные рискованные пути в коде, но не доказывает исчезновение ошибки на каждом ПК. При ошибке скопируйте диагностику правым кликом по Ghost Mode. Windows API подтверждает флаг для конкретного HWND; он не гарантирует результат во всех способах захвата экрана. [Документация Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity).

Время первого токена и полного ответа **не измерялось на Gemini**: действующий API-ключ и одинаковые тестовые запросы не предоставлены этой среде. Звуковое оборудование Fifine, системный WASAPI и Windows 11 здесь также не проверялись физически; автоматические тесты этих путей выполнялись с имитацией устройств. Реальный тест: запустите `python main.py`, выберите правильное аудиоустройство, задайте одинаковые вопросы до и после обновления и посмотрите «ВІКНО ЗАМІРІВ» в настройках. При `PHANTOM_TIMING=1` журнал покажет первый текст и полное время ответа без записи ключей.

Для OFF и Reduced используется настройка Windows `SPI_GETCLIENTAREAANIMATION` и [управление эффектами Qt](https://doc.qt.io/qt-6/qapplication.html#isEffectEnabled). Системные анимации других приложений программа не меняет.
