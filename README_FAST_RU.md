# EXAM AI — украинское распознавание и быстрые ответы Gemini, версия 7

## Установка поверх основной папки

1. Закройте EXAM AI и сделайте копию папки приложения.
2. Распакуйте всё содержимое `EXAM_AI_FAST_v7_full_source.zip` прямо в папку с запускаемым вами `main.py`, с заменой файлов.
3. Если у вас установлена предыдущая версия, удалите из этой же папки старые `stt_realtime.py`, `benchmark_streaming.py` и `test_dual_provider.py`. Новый код их не вызывает, но они относятся к удалённому OpenAI.
4. Откройте PowerShell в папке приложения и выполните:

   ```powershell
   python -m pip install -r requirements.txt
   python main.py
   ```

Ваши `config.json` и `exam_assistant.db` не входят в архив. История и настройки остаются на месте. Старые поля OpenAI игнорируются; после сохранения настроек новый `config.json` будет записан без них. Ключ Gemini вводится в настройках и остаётся только в памяти до закрытия программы; при новом запуске введите его снова либо задайте переменную среды `GEMINI_API_KEY`. Не пересылайте ключ.

## Единственный маршрут распознавания

При наличии ключа программа подключает **Gemini 3.5 Transcribe Live**. Он принимает звук небольшими фрагментами, отдаёт промежуточный украинский текст во время речи и итоговый после фразы. Отправляются только отрезки с речью, выделенные VAD. Настройка `uk-UA` подсказывает язык; режим Smart и предметные термины помогают распознавать слова. При отсутствии ключа, ошибке, пустом итоге, русском фрагменте или долгом ожидании сохранённая фраза переходит в локальный Whisper. Всплывающий русский промежуточный фрагмент скрывается. По умолчанию распознавание работает на украинском. В настройках можно выбрать русский, английский или автоопределение через локальный Whisper. Сохраните настройки и перезапустите прослушивание. `uk-UA` — подсказка модели, а не гарантия точности; при повторении ошибки нужен образец звука для диагностики. [Документация Google о Live Transcription](https://ai.google.dev/gemini-api/docs/live-api/live-transcribe).

Для вопроса со скриншота локальная коррекция преобразует `Що така дезномція.` в `Що таке диз’юнкція.`. Она также приводит разные символы украинского апострофа к `’`, исправляет пропущенный апостроф в терминах словаря и осторожно исправляет близкие написания. Неизвестные обычные слова не переписываются по догадке. Добавляйте собственные устойчивые ошибки в `speech_glossary.json` как пары «ошибка» → «правильно», затем перезапускайте приложение. Не добавляйте туда секреты.

Для вашего нового примера словарь преобразует `Шо таке рекусривний метод?` в `Що таке рекурсивний метод?`. `Рекурсивний метод` также передаётся Gemini Live как предметный термин и добавлен в подсказку локальному Whisper. Если система снова выдаст `Это ты не`, этот текст не будет автоматически отправлен ИИ: приложение повторно проверит сохранённую звуковую фразу локально.

## Скорость и источник звука

В настройках выберите **Системний звук (Loopback)**, если вопрос звучит в динамиках/наушниках выбранного устройства вывода Windows, либо **Мікрофон**, если вопрос произносят рядом с вами. Захват берёт 20-мс блоки, при необходимости переключается с float32 на PCM16. Silero VAD хранит короткий фрагмент перед началом речи и завершает фразу после паузы; при недоступности Silero используется детектор громкости. [Описание WASAPI loopback](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording).

Ответы даёт только Gemini. Для скорости выберите в настройках `gemini-3.5-flash-lite`; запрос использует минимальный уровень размышления и показывает текст по мере поступления. Инструкция просит дать на ясный учебный вопрос 2–3 предложения до 75 слов. Убрано повторное ожидание другой модели после ошибки сервера 504: такой повтор мог добавлять ещё до 12 секунд. Кнопка **Очистити все** над вопросом очищает вопрос и ответ одновременно; уже запущенный ответ больше не вернётся в очищенные поля. Одинаковый автоматически распознанный вопрос не отправляется повторно в течение восьми секунд.

Если модель ответов возвращает **HTTP 429**, программа сразу пробует вторую модель Gemini (`gemini-3.1-flash-lite`) тем же ключом и запоминает лимит первой модели на минуту. Если обе модели ограничены, приложение сообщает об этом без повторных бесполезных запросов в течение минуты. Лимиты Google действуют **на проект, а не на отдельный ключ**; смена ключа того же проекта не восстанавливает квоту. У отдельных моделей могут быть разные лимиты, поэтому переключение иногда помогает, но не гарантирует ответ в ту же секунду. Gemini STT HTTP 429 относится к распознаванию и переводит речь на локальный Whisper. [Правила лимитов Google](https://ai.google.dev/gemini-api/docs/rate-limits), [коды ошибок](https://ai.google.dev/gemini-api/docs/api-errors).

**HTTP 503** означает временную недоступность Gemini, а не ошибку распознавания и не исчерпание токенов. Если сервер сразу отклоняет запрос, приложение один раз пробует другую модель Gemini и временно не обращается к отказавшей модели. Если ошибка пришла уже после заметного ожидания, второй запрос не добавляется, чтобы не удваивать задержку. При недоступности обеих моделей ответ без сервиса Gemini получить нельзя.

На этой машине локальный Whisper `base` на CPU расшифровывал шесть имеющихся коротких записей с медианой примерно **0,98 с на фразу после загрузки модели**. Записи русские, поэтому их ошибки не показывают точность на украинском. Локальная коррекция вопроса со скриншота выполнялась в среднем за **0,054 мс** на 10 000 повторов. Модель Whisper `small` не была полностью загружена и не сравнивалась. Живой Gemini Live с вашим ключом здесь не проверялся: ключ не предоставлялся среде. Выбор основного режима основан на поддержке потока, промежуточного текста и `uk-UA` в документации Google и проверке кода без сетевых запросов; точность на вашей речи требует проверки ваших украинских записей.

Для проверки после установки включите **Системний звук (Loopback)** и воспроизведите вопрос «Що таке рекурсивний метод?». Проверьте окончательный текст и ответ; затем воспроизведите ещё один украинский вопрос. Нажмите **Очистити все** во время ответа: оба поля должны остаться пустыми. Если видите сообщение о переключении на Whisper, сохраните его текст без ключа: оно покажет, что именно помешало Gemini Live. Для диагностики задержки на своей машине можно включить время этапов:

```powershell
$env:PHANTOM_TIMING = '1'
python main.py
```


В этой версии резервный Whisper получает фразу через 650 мс после локального завершения речи, если Gemini ещё не вернул результат. Первый пригодный результат принимается один раз. Холодная загрузка Whisper по-прежнему может занять дополнительное время. Значение паузы VAD в настройках оставлено прежним.

В журнале vad endpoint_ms показывает время от получения последнего голосового блока до завершения фразы, llm first_text_ms показывает время от подготовки запроса до первого текста модели, а voice first_ui_text_ms показывает время от последнего голосового блока до обновления поля ответа. Последняя метрика включает ожидание предыдущей задачи и измеряет первый видимый текст, который может быть началом предложения. В этих метках нет текста вопроса или ключей.

Для синтетического сравнения запустите python benchmark_voice.py в папке этой версии. Для сравнения с v7 передайте путь к распакованной исходной папке, например python benchmark_voice.py C:/path/to/original. Скрипт сравнивает VAD и момент запуска резерва, добавляя одинаковые искусственные задержки STT и LLM.

Автономная проверка проекта выполняется командой `python -m unittest discover -q` в чистой распакованной папке. Она не отправляет звук и ключи в сеть. В архиве нет `config.json`, базы данных, аудиофайлов и API-ключей.


## FAST, SMART и отсчёт после вопроса

FAST по умолчанию формирует короткий ответ и передаёт до двух найденных фрагментов конспекта. SMART использует до четырёх фрагментов, больший бюджет ответа и Gemini 3.5 Flash вместо Flash-Lite при стандартной настройке. Чтобы расширить ответ, выберите SMART и отправьте вопрос снова. Режим фиксируется в момент постановки вопроса в очередь.

Для голосового вопроса отсчёт начинается от последнего голосового блока VAD. Для ручного ввода он начинается от отправки. Через две секунды интерфейс может показать статус задержки. Сетевой тайм-аут отсчитывает отсутствие сетевых данных, и приложение не прерывает активный поток по общему восьмисекундному таймеру. Для явной отмены используйте «Очистити все». История вопросов и ответов сохраняется локально только после включения соответствующей настройки.

Сообщение «З’єднання перервано. Відповідь неповна.» означает, что часть текста пришла до ошибки потока. При PHANTOM_TIMING=1 строка llm stream_error содержит класс ошибки и HTTP-код, если он доступен. В ней нет текста вопроса, ответа или ключа.


## HTTP 400

Gemini 3.5 Flash-Lite и 3.1 Flash-Lite используют штатный режим minimal. Для 3.5 Flash запрос передаёт REST-параметр thinkingLevel. При HTTP 400 приложение различает недействительный ключ, ограничение ключа, условия доступа и отказ в параметрах запроса, когда API возвращает соответствующие сведения. Сырой ответ с диагностикой не отображается.

Если сервер отклоняет параметры с HTTP 400, приложение один раз пробует тот же текстовый запрос без отдельных настроек генерации. При успехе этот формат используется для той же модели до перезапуска. Ошибки ключа и доступа не запускают повтор. Сетевое время ожидания остаётся на стороне приложения.


## Диагностика WASAPI Loopback

В режиме «Системний звук» выберите Logitech PRO X [Loopback] или «Пристрій відтворення Windows за замовчуванням». Устройство по умолчанию определяется при каждом запуске захвата. Если Windows сменила устройство во время прослушивания, остановите и запустите захват снова.

    $env:PHANTOM_AUDIO_DIAGNOSTICS = '1'
    python main.py

Журнал показывает версию бэкенда, запрошенный индекс, индекс выхода WASAPI по умолчанию, выбранный loopback-вход, формат, частоту, число каналов и исходное исключение PortAudio. Индексы PortAudio действуют для текущего списка устройств. Аудио в журнал не записывается.

На Logitech PRO X воспроизведена ошибка OSError(-9996, 'Invalid device') при открытии двух каналов на 48000 Гц. Восьмиканальный поток на той же частоте открылся, и диагностический тон 1 кГц был получен во всех трёх путях выбора устройства. Многоканальный поток преобразуется в моно после захвата.

## Таймауты Gemini и повторное подключение

Сообщение о сетевом таймауте после вопроса относится к HTTP-запросу LLM. Подключение ограничено 5 с, отсутствие данных при чтении — 12 с. Интерфейс отдельно сообщает о таймауте подключения, ожидании начала и обрыве уже начатого потока. При быстром отказе TCP/TLS выполняется один повтор подключения. Запрос после ошибки чтения или записи не отправляется заново.

У Gemini Live отдельное подключение и штатный ping/pong библиотеки WebSocket. Обычная тишина не запускает таймер LLM. PCM-хвост отправляется до activityEnd. Если финал задерживается, Whisper получает буфер по прежнему порогу 650 мс. После реального разрыва запускается одно фоновое переподключение на сеанс прослушивания. Незавершённый старый вопрос остаётся в локальном декодере и не пересылается новому WebSocket.

При PHANTOM_TIMING=1 смотрите live_audio_send_ms, live_end_queue_ms, live_first_event_from_audio_ms, live_final_from_end_send_ms, llm_start_from_speech_end_ms и llm_ttft_ms. Первый набор относится к STT, последний — к генерации. Строки связаны через request_id и не содержат звук, текст или ключ.

## Семантический поиск по конспектам

Импортируйте конспекты в ExamAI обычным способом. Закройте приложение и выполните команды из папки, где лежит рабочая база `exam_assistant.db`.

```powershell
python -m pip install -r requirements-rag.txt
python index_rag.py --download-model
python main.py
```

Первый запуск скачивает около 135 МБ в `models/semantic-e5-small`. При следующих запусках `python index_rag.py` использует локальную модель и кодирует только новые уникальные фрагменты. При необходимости укажите путь к базе через `--db`. Текст обрабатывается локально. После добавления или замены конспектов повторите индексацию и перезапустите приложение, чтобы включить новые фрагменты в семантический поиск. До этого их находит BM25. Удалённые фрагменты исключаются из выдачи сразу. Векторы по хешу содержимого остаются в таблице `rag_embedding_cache` для повторного импорта.

При запуске приложение в фоне загружает модель и до 50 000 последних проиндексированных фрагментов. Голосовой запрос объединяет результаты BM25 и семантического поиска и передаёт до 1 600 символов в FAST или 3 200 в SMART. Если модель ещё загружается, занята, недоступна или не успевает в общий бюджет поиска 100 мс, используется BM25. При `PHANTOM_TIMING=1` выводятся `lexical_ms`, `semantic_ms`, `semantic_status`, число найденных фрагментов и размер контекста. Строки не содержат текст запроса или конспекта.

Для сравнения задержки используйте `python benchmark_rag.py` и `python benchmark_rag.py --semantic`. Для проверки русского, украинского и английского на установленной модели задайте `$env:EXAMAI_TEST_REAL_RAG = '1'` и выполните `python -m unittest -v test_semantic_rag`.
